# Security Policy

## Supported Versions

We currently only support the latest version of this project.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it by emailing **[bahattinyunuscetin@gmail.com]**. 

Please include:
- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix if necessary.
